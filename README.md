# STS — Sean's Transportation Service

Static demo website for Sean's Transportation Service (STS), a vehicle rental and transportation fleet based in Guyana.

## Structure
- `index.html`, `about.html`, `services.html`, `fleet.html`, `catalog.html`, `quote.html`, `contact.html` — site pages
- `assets/css/` — stylesheet
- `assets/js/` — site logic and fleet data
- `assets/images/` — fleet, brand, and hero imagery
